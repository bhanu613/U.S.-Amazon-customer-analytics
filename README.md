## Data Source

This project uses the **Open e-commerce 1.0** dataset:  
"Five years of crowdsourced U.S. Amazon purchase histories with user demographics"  
Available on Harvard Dataverse: https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/YGLYDY

To reproduce the analysis:

1. Download `amazon-purchases.csv`, `survey.csv`, and `category_map.csv` from the data source or course materials.
2. Place them in a local or Colab directory and update the paths in the notebook accordingly.
